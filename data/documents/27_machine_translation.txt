TITLE: Machine Translation
PURPOSE: Retrieval-friendly knowledge for a generative question-answering system.

SECTION: Core concepts
Machine translation is the automatic translation of text or speech from one language to another.
The source language is the language of the input.
The target language is the language of the generated translation.
An MT system maps source-language input to target-language output.
Translation quality depends on linguistic structure, context, domain, and training data.
Parallel data contains aligned examples in two languages.
A bilingual corpus can be used to train or evaluate translation systems.
Monolingual data contains text in one language and can support some MT methods.
Language pairs can have very different word order and grammatical structure.
Translation is not simple word substitution because meaning is expressed compositionally.

SECTION: Rule-based and statistical MT
Rule-based machine translation uses linguistic rules, dictionaries, and grammar resources.
Direct translation systems transform source text using relatively shallow mappings.
Transfer-based systems represent source structures and apply language-specific transfer rules.
Interlingua approaches attempt to map different languages into a language-independent representation.
Statistical machine translation learns translation probabilities from bilingual data.
Phrase-based SMT translates sequences of words or phrases rather than isolated words.
Word alignment estimates relationships between source and target tokens.
Translation models estimate how source phrases correspond to target phrases.
Language models help rank fluent target-language sequences in classical SMT.
Decoding searches for a high-scoring target sentence under the model.

SECTION: Neural machine translation
Neural machine translation uses neural networks to generate translations.
Sequence-to-sequence models encode a source sequence and decode a target sequence.
An encoder produces representations of the source input.
A decoder generates target tokens sequentially or using parallel decoding mechanisms.
Attention allows the decoder to focus on relevant source representations.
Transformer architectures use self-attention and became central to modern NMT.
Self-attention allows tokens to interact with other tokens in the same sequence.
Cross-attention connects target-side representations with source-side representations.
Autoregressive decoders generate output tokens conditioned on previously generated tokens.
Some modern translation systems use encoder-decoder transformer architectures.

SECTION: Tokenization and vocabulary
Subword tokenization breaks rare or unknown words into smaller units.
Byte-pair encoding is a common family of subword segmentation methods.
SentencePiece can learn tokenization directly from raw text.
Subword units reduce the number of unknown words compared with word-only vocabularies.
Vocabulary size affects memory, sequence length, and coverage.
Character-level models can represent arbitrary spelling but may require longer sequences.
Language-specific tokenization rules can improve processing for some scripts.
Normalization must account for Unicode and language-specific writing conventions.
Numbers, dates, names, and URLs may need special treatment in translation pipelines.
Tokenization choices can affect both training efficiency and translation quality.

SECTION: Training and inference
Supervised NMT training commonly minimizes a loss between reference and generated target tokens.
Teacher forcing provides reference previous tokens during training in autoregressive models.
Cross-entropy is commonly used as a token-level training objective.
Batching groups examples to improve hardware utilization.
Padding allows variable-length sequences to be processed in batches.
Attention masks prevent models from attending to invalid padding or future tokens when required.
Beam search explores multiple candidate translations during autoregressive decoding.
Greedy decoding chooses the highest-probability next token at each step.
Sampling can generate diverse outputs but is less common for deterministic translation.
Length penalties can influence the preference for short or long candidate translations.

SECTION: Quality and evaluation
BLEU is an automatic metric based primarily on n-gram overlap with reference translations.
BLEU can be useful for comparing systems under consistent evaluation settings.
BLEU does not fully capture meaning preservation or linguistic adequacy.
chrF evaluates character n-gram similarity and can be useful for morphologically rich languages.
TER measures the amount of editing required to transform a system output toward a reference.
COMET-style learned metrics use neural representations to estimate translation quality.
Human evaluation can assess adequacy, fluency, terminology, and errors.
Adequacy concerns how well the translation preserves source meaning.
Fluency concerns how natural and grammatically appropriate the target output is.
Evaluation should use held-out test data and clearly documented language pairs and domains.

SECTION: Translation challenges
Word sense ambiguity occurs when a source word has multiple possible meanings.
Long-distance dependencies can make translation difficult when relevant words are far apart.
Idioms often require meaning-level translation rather than literal substitution.
Named entities may need transliteration, preservation, or established translations.
Low-resource languages have limited parallel training data.
Domain shift occurs when training data differs substantially from the deployment domain.
Code-switching can combine multiple languages within the same input.
Rare terminology can be difficult when it is absent from training data.
Gender and politeness can require information that is implicit or ambiguous in the source.
Pronoun resolution can require context beyond a single sentence.

SECTION: Multilingual and transfer learning
Multilingual MT trains one model to handle multiple language pairs.
Shared parameters can allow knowledge transfer between related languages.
Zero-shot translation attempts to translate between languages without direct parallel training examples.
Language tags can tell a multilingual model which target language to generate.
Transfer learning can improve low-resource translation by reusing multilingual representations.
Related languages may benefit from shared vocabulary and representations.
Unrelated languages may require different tokenization or language-specific adaptation.
Back-translation creates synthetic parallel data from monolingual target-language text.
Knowledge distillation can transfer behavior from a larger translation model to a smaller model.
Parameter-efficient adaptation can update a smaller portion of model parameters for a language or domain.

SECTION: Safety, bias, and practical use
Machine translation can reproduce biases present in training data.
Sensitive content should be handled according to the privacy and security requirements of the application.
Translation errors can be consequential in legal, medical, or safety-critical settings.
Human review is appropriate when translation accuracy has high consequences.
Terminology constraints can help preserve required product or technical terms.
Glossaries can provide approved translations for recurring domain terminology.
Post-editing is the process of correcting machine-generated translations.
Translation memory systems can reuse previously translated segments.
Quality estimation predicts translation quality without necessarily requiring a reference translation.
Deployment monitoring should track language-specific and domain-specific error patterns.
