TITLE: Dependency and Constituency Parsing
PURPOSE: Retrieval-friendly knowledge for a generative question-answering system.

SECTION: Core concepts
Parsing analyzes the grammatical structure of a sentence.
Constituency parsing represents a sentence as nested phrases or constituents.
Dependency parsing represents words as nodes connected by directed grammatical relations.
A parse tree is a structured representation of syntactic relationships.
The root of a dependency tree is the main syntactic head of the sentence.
A constituent is a contiguous group of words functioning as a grammatical unit.
A phrase can be categorized as a noun phrase, verb phrase, prepositional phrase, or another phrase type.
Dependency relations connect a dependent word to a head word.
Part-of-speech tags provide lexical categories that can support parsing.
Syntactic parsing is useful for information extraction, question answering, and language understanding.

SECTION: Constituency grammar
A context-free grammar represents productions that describe how constituents can be formed.
A nonterminal symbol represents a syntactic category such as NP or VP.
A terminal symbol represents a word or lexical item in a grammar.
A production rule specifies how a nonterminal can expand.
A sentence can be represented using an S node in traditional grammar notation.
NP commonly denotes a noun phrase.
VP commonly denotes a verb phrase.
PP commonly denotes a prepositional phrase.
Constituency trees are hierarchical and explicitly represent phrase nesting.
Grammar-based parsing searches for a tree consistent with grammar rules and the input sentence.

SECTION: Dependency grammar
Dependency parsing represents grammatical structure using head-dependent relations.
Each non-root token normally has one syntactic head in a basic dependency tree.
The root token is connected to the sentence through the root relation.
Common dependency labels include subject, object, modifier, and case-related relations.
Universal Dependencies provides a cross-linguistic framework for dependency annotation.
Dependency trees can represent long-distance relations without requiring phrase nodes.
Head selection is central to dependency parsing.
Dependency labels encode the grammatical function of a dependent relative to its head.
Dependency graphs are useful for extracting predicate-argument structures.
Dependency parses can support relation extraction and semantic interpretation.

SECTION: Parsing algorithms
Top-down parsing begins with the start symbol and expands grammar rules toward terminals.
Bottom-up parsing builds larger structures from observed tokens.
Chart parsing stores partial results to avoid repeated computation.
CYK parsing is a dynamic-programming algorithm for suitable context-free grammars.
Shift-reduce parsing uses a stack and a sequence of transition actions.
Transition-based dependency parsing predicts actions that construct a dependency tree.
Graph-based dependency parsing scores possible tree structures and searches for a high-scoring tree.
Beam search can keep multiple partial parsing hypotheses.
Dynamic programming can reduce repeated computation in parsing.
Parsing algorithms trade off accuracy, speed, grammar flexibility, and implementation complexity.

SECTION: Ambiguity
Syntactic ambiguity occurs when a sentence can have more than one plausible parse.
Attachment ambiguity occurs when a modifier can attach to different parts of a sentence.
Prepositional phrase attachment is a common source of ambiguity.
Coordination ambiguity can arise when it is unclear how conjuncts are grouped.
Lexical ambiguity occurs when a word has multiple possible grammatical or semantic interpretations.
Probabilistic parsers rank competing parses using learned scores or probabilities.
Context can help resolve syntactic ambiguity.
World knowledge may be needed when syntax alone does not determine the intended interpretation.
Parser errors can propagate into downstream information extraction tasks.
Ambiguity should be considered when interpreting a single parse as definitive.

SECTION: Dependency relations
Nominal subject relations connect a predicate to its grammatical subject.
Direct object relations connect a predicate to an object.
Indirect object relations represent certain recipient or beneficiary structures.
Adjectival modifiers connect descriptive adjectives to nouns.
Adverbial modifiers connect many adverbs or modifying phrases to predicates.
Determiners can represent words such as articles modifying nouns.
Case relations can represent prepositions or case markers in dependency frameworks.
Conjunct relations represent coordination between elements.
Compound relations can represent multiword or compound constructions.
Dependency labels are framework-specific and should be interpreted according to the annotation scheme.

SECTION: Constituency structures
Constituency parsing can reveal nested noun phrases.
Verb phrases can contain auxiliaries, verbs, objects, and modifiers.
Prepositional phrases often contain a preposition and a noun phrase.
Adjective phrases can contain an adjective and its modifiers.
Adverb phrases can contain an adverb and modifiers.
Coordination can be represented as a phrase containing multiple coordinated constituents.
Unary productions contain a single child and may be normalized in some treebanks.
Tree depth measures the level of nesting in a constituency tree.
Span boundaries identify the start and end positions of a constituent.
Constituent labels depend on the grammar or treebank used for training and evaluation.

SECTION: Parsing models and representations
Traditional parsers use manually designed grammars or statistical models.
Probabilistic context-free grammars assign probabilities to grammar productions.
Neural parsers use learned representations rather than only handcrafted rules.
Transformer encoders can provide contextual token representations for parsing.
Graph neural methods can model relationships among candidate syntactic structures.
Character or subword representations can help handle unknown words and morphology.
Pretrained language models can be fine-tuned for dependency or constituency parsing.
Multilingual parsers aim to support multiple languages with shared or language-specific parameters.
Domain adaptation can improve parsing for specialized text.
Parser confidence scores can help downstream systems identify uncertain analyses.

SECTION: Evaluation and applications
Dependency parsing is commonly evaluated using unlabeled attachment score.
Unlabeled attachment score measures whether each token has the correct head.
Labeled attachment score additionally requires the dependency relation label to be correct.
Constituency parsing can be evaluated using bracket or span-based precision and recall.
Exact tree match requires the predicted tree to match the reference under the evaluation definition.
Parsing can support question answering by identifying predicates, subjects, and objects.
Parsing can support information extraction by exposing syntactic relations.
Parsing can support semantic role labeling as a source of syntactic features.
Search and text classification systems can use syntactic features when useful.
Parsing errors should be analyzed by sentence type, domain, and language.

SECTION: Limitations and practical use
Natural language syntax contains ambiguity and exceptions that make perfect parsing difficult.
Informal text may contain fragments, spelling errors, emojis, or unconventional punctuation.
Parser performance can differ substantially across languages.
Treebanks encode annotation conventions that influence what a parser learns.
Domain shift can reduce accuracy when deployment text differs from training data.
Long sentences can be computationally and linguistically challenging.
Coordination and attachment structures can produce difficult errors.
Parsing should be treated as an analysis layer rather than unquestionable truth.
Combining parsing with contextual language models can improve robustness in some settings.
For QA systems, parsing is most useful when its output contributes evidence to a broader reasoning pipeline.
