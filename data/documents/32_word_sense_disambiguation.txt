TITLE: Word Sense Disambiguation
PURPOSE: Retrieval-friendly NLP knowledge for a generative question-answering system.
USAGE: Each statement is written as an atomic knowledge unit so semantic retrieval can return focused evidence.

SECTION: Core concepts
Word sense disambiguation, or WSD, determines which meaning of a word is intended in a particular context.
A word may have multiple senses, making its meaning dependent on surrounding text.
Lexical ambiguity occurs when a word or expression has more than one plausible interpretation.
Polysemy occurs when related meanings are associated with the same lexical form.
Homonymy occurs when the same form is associated with unrelated meanings.
A sense inventory is a defined collection of meanings for words.
A dictionary or lexical database can provide candidate senses.
Context is the main evidence used to distinguish competing word senses.
WSD is a word-level semantic interpretation task.
WSD can support downstream tasks such as translation, search, question answering, and information extraction.

SECTION: Types of ambiguity
Part-of-speech ambiguity occurs when a word can belong to different grammatical categories.
Lexical semantic ambiguity occurs when the same lexical item has multiple meanings.
Local ambiguity can sometimes be resolved using nearby words.
Long-range ambiguity may require information from earlier or later sentences.
Domain ambiguity occurs when a term has different meanings in different fields.
Technical terminology can have a specialized sense that differs from everyday usage.
Named entities can also be ambiguous when different entities share a name.
Pronouns create reference ambiguity rather than traditional word-sense ambiguity.
Metaphorical language can create an interpretation that differs from the literal dictionary sense.
Contextual cues can include syntax, neighboring words, topic, and discourse context.

SECTION: Sense inventories and lexical resources
WordNet is a lexical database that organizes English words into synsets and semantic relations.
A synset groups words that can express a particular concept or sense.
Glosses provide textual descriptions of lexical senses.
Hypernym relations connect a concept to a more general concept.
Hyponym relations connect a concept to a more specific concept.
Meronym relations represent part-whole relationships.
Lexical resources may provide example sentences that help distinguish senses.
Different applications may require different sense inventories.
Very fine-grained sense inventories can make WSD harder because distinctions become subtle.
Coarse-grained sense inventories merge closely related meanings to simplify classification.

SECTION: Knowledge-based WSD
Knowledge-based WSD uses lexical or semantic resources instead of requiring large labeled training sets.
The Lesk algorithm compares dictionary glosses with the context of an ambiguous word.
Gloss overlap methods select a sense whose definition shares words with the surrounding context.
Semantic similarity measures can compare candidate senses using lexical relations.
Graph-based methods represent senses and semantic relations as graphs.
Knowledge-based methods can work when annotated WSD data is limited.
Knowledge-based systems depend on the coverage and quality of their lexical resources.
Glosses may be too short to provide enough evidence for some ambiguous words.
Domain-specific terminology may not be adequately represented in general lexical databases.
Hybrid methods can combine lexical knowledge with learned contextual representations.

SECTION: Supervised and neural WSD
Supervised WSD treats sense selection as a classification problem.
A supervised classifier learns from examples where the correct sense is annotated.
Features can include neighboring words, part-of-speech tags, syntactic information, and collocations.
Traditional classifiers include naive Bayes, decision trees, support vector machines, and logistic regression.
Contextual language models provide representations that depend on surrounding words.
Transformer encoders can be fine-tuned for word-sense classification.
Gloss-informed models can compare a contextual word representation with candidate sense descriptions.
Few-shot approaches can use a small number of labeled examples.
Zero-shot approaches attempt sense selection without task-specific labeled examples.
Neural methods can generalize better across contexts but still depend on sense definitions and data quality.

SECTION: Context and features
Collocations are recurring word combinations that provide useful clues for WSD.
Part-of-speech information can eliminate senses that are incompatible with the grammatical category.
Dependency relations can reveal how an ambiguous word is used syntactically.
Nearby content words often provide strong evidence about intended meaning.
Topic information can help distinguish senses associated with different domains.
Sentence-level context is often more informative than the ambiguous word alone.
Document-level context can resolve ambiguity when sentence-level evidence is insufficient.
Previous dialogue turns can help resolve a word's intended sense in conversation.
Semantic role information can provide clues about how an ambiguous predicate is being used.
Context windows should be large enough to capture relevant evidence without introducing excessive noise.

SECTION: Evaluation
WSD accuracy measures the proportion of ambiguous instances assigned the correct sense.
Precision and recall can be used when systems abstain or only predict selected senses.
Fine-grained WSD evaluation is harder because closely related senses can be difficult to distinguish.
Lexical sample evaluation tests a selected set of ambiguous words.
All-words WSD evaluates ambiguous words throughout a text.
Intrinsic evaluation compares predicted senses against human annotations.
Extrinsic evaluation measures whether WSD improves a downstream application.
Inter-annotator agreement indicates how consistently human annotators distinguish senses.
Low agreement can indicate that the sense inventory contains unclear distinctions.
Evaluation should specify the language, sense inventory, domain, and test set.

SECTION: Applications and limitations
Machine translation can use WSD to select an appropriate target-language translation.
Search systems can use WSD to distinguish queries with multiple meanings.
Question answering can use WSD to interpret ambiguous terms in a question.
Information extraction can use WSD to improve semantic interpretation of extracted relations.
Text classification can benefit from distinguishing domain-specific meanings.
Semantic search can use sense-aware representations to improve matching.
WSD is difficult when context does not contain enough information.
Rare senses are often harder to identify because training examples are limited.
Domain shift can change which sense is most common in a dataset.
Human interpretation may remain necessary for highly ambiguous or specialized text.
