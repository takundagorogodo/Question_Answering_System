Transformers and the Attention Mechanism

The transformer is a type of neural network architecture, introduced in 2017, that has become the foundation of nearly all modern language models, including the ones used in retrieval-augmented generation systems. Before transformers, NLP models typically processed text one word at a time, in order, using architectures called recurrent neural networks. This sequential processing was slow and made it difficult for the model to remember information from far earlier in a long piece of text.

The transformer's key innovation is a mechanism called attention. Attention allows the model to look at all the words in a sentence at once and learn which other words are most relevant to understanding each particular word, regardless of how far apart they are in the sentence. For example, in the sentence "The trophy did not fit in the suitcase because it was too big," attention helps the model figure out that "it" most likely refers to the trophy rather than the suitcase, by weighing the relationship between "it" and every other word in the sentence.

A transformer model is typically built from stacked layers, each containing an attention mechanism followed by a simple feed-forward network. By stacking many of these layers, the model builds up increasingly rich and abstract representations of the input text, layer by layer.

Transformer architectures are often described as having two main components: an encoder, which reads and processes an input sequence into a rich internal representation, and a decoder, which generates an output sequence, often one token at a time. Some models use only an encoder (useful for understanding tasks like classification), some use only a decoder (useful for pure text generation), and some use a full encoder-decoder architecture, which is well suited for tasks where an input sequence needs to be transformed into a related but different output sequence, such as translation or generative question answering.

The reason transformers matter so much for a project like this one is that both the embedding model used for retrieval and the generative model used for answering are, under the hood, transformer-based. Understanding attention explains why these models can connect a user's question to relevant information anywhere in a retrieved passage, not just information located near the start.
