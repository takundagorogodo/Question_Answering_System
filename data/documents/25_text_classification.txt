
TEXT CLASSIFICATION

NLP KNOWLEDGE BASE

Text classification assigns labels to text.
Text classification converts text into predefined categories.
Input can be a word, sentence, paragraph, document, email, or message.
Output can contain one or more class labels.
Supervised classification uses labeled training examples.
Binary classification has two classes.
Multiclass classification has more than two possible classes.
Multilabel classification allows multiple labels for one input.
Sentiment analysis is a common text-classification task.
Spam detection is a common text-classification task.
Topic classification assigns documents to topics.
Intent classification identifies the purpose of a user message.
Language identification predicts the language of text.
News classification assigns articles to categories.
Question classification identifies question types.
Customer-support systems can classify incoming requests.
Text preprocessing prepares raw text for a model.
Tokenization divides text into tokens.
Tokens may be words, subwords, or characters.
Lowercasing can reduce vocabulary variation.
Stop-word removal can be useful for some classical models.
Stemming reduces words to stems.
Lemmatization maps words to base forms.
Transformer models commonly use subword tokenization.
Bag of Words is a classical text representation.
Bag of Words is also called BoW.
BoW represents text using vocabulary features.
Count-based BoW records term occurrences.
Binary BoW records term presence.
Basic BoW ignores word order.
BoW vectors are often sparse.
TF-IDF means Term Frequency-Inverse Document Frequency.
TF-IDF weights terms according to document and corpus frequency.
Common terms receive lower IDF weight.
Distinctive terms can receive higher TF-IDF weight.
TF-IDF works well with classical classifiers.
An n-gram is a contiguous sequence of tokens.
A unigram contains one token.
A bigram contains two tokens.
A trigram contains three tokens.
N-grams preserve limited local word order.
Character n-grams can handle spelling variations.
Naive Bayes is a common text-classification baseline.
Multinomial Naive Bayes works with word-count features.
Logistic regression works well with sparse text features.
Support Vector Machines can work well with TF-IDF.
K-nearest neighbors can use vector similarity.
Decision trees can classify numerical text features.
Random forests can classify suitable text features.
CNNs can capture local text patterns.
RNNs can model sequential text information.
LSTMs can model sequence context.
Transformers can create contextual text representations.
BERT can be fine-tuned for text classification.
A classification head produces class scores.
Softmax is common for mutually exclusive classes.
Sigmoid outputs can support multilabel classification.
Cross-entropy is a common classification loss.
Training data is used to learn model parameters.
Validation data can tune hyperparameters.
Test data is used for final evaluation.
Data leakage can produce misleading evaluation results.
Class imbalance occurs when classes have unequal frequencies.
Class weights can increase minority-class importance.
Oversampling can increase minority examples.
Undersampling can reduce majority examples.
Accuracy measures the proportion of correct predictions.
Precision measures correctness among predicted positives.
Recall measures how many actual positives are detected.
F1-score combines precision and recall.
A confusion matrix shows class prediction errors.
Macro averaging gives equal weight to classes.
Micro averaging aggregates decisions across classes.
Text classification can support question-answering systems.
Question classification can route questions to knowledge-base sections.
Classification can reduce retrieval from unrelated documents.
Classification can be combined with TF-IDF retrieval.
Classification can be combined with embeddings.
Classification alone does not generate a complete answer.
Ambiguous text can be difficult to classify.
Domain changes can reduce model performance.
Rare classes can be difficult to learn.
Poor labels can reduce model quality.
Overfitting reduces generalization to unseen text.
Underfitting occurs when a model is too simple.
Evaluation should use representative test data.
