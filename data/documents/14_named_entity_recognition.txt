ORD2VEC

DEFINITION
Word2Vec is a word-embedding technique.
Word2Vec represents words as dense numerical vectors.
Word2Vec learns vectors from word-context relationships.
The distributional hypothesis motivates Word2Vec.
The distributional hypothesis says that similar contexts indicate related meanings.
Word2Vec was developed by researchers at Google.
Word2Vec became an influential method in NLP.
Word vectors can be compared using cosine similarity.
Similar words can occupy nearby regions in embedding space.
Word2Vec learns representations from a training corpus.
Embedding dimensions are learned rather than manually assigned.

CBOW
CBOW stands for Continuous Bag of Words.
CBOW predicts a target word from surrounding context words.
Context words are used as input in the CBOW architecture.
The target word is the prediction output.
CBOW can train efficiently on large corpora.
CBOW often performs well for frequent words.
Window size controls how much surrounding context is used.
Larger windows can capture broader topical relationships.
Smaller windows can capture more local syntactic relationships.
CBOW learns word representations during prediction training.

SKIP-GRAM
Skip-gram predicts surrounding context words from a target word.
Skip-gram reverses the prediction direction used by CBOW.
The target word is provided as input.
Nearby context words become prediction targets.
Skip-gram can work well for less frequent words.
Negative sampling can make Skip-gram training more efficient.
Hierarchical softmax is another training option.
Context-window size affects the learned representations.
Training examples are created from word-context pairs.
Word2Vec does not require manually created semantic labels.

EMBEDDINGS AND RELATIONSHIPS
A Word2Vec embedding is a dense vector.
Dense vectors usually have many non-zero values.
Vector distance can indicate contextual similarity.
Cosine similarity is commonly used to compare word embeddings.
Vector arithmetic can sometimes reflect learned semantic relationships.
Embedding relationships are statistical rather than guaranteed logical rules.
The quality of relationships depends on the training corpus.
A domain-specific corpus can produce domain-specific representations.
Different Word2Vec models can assign different vectors to the same word.
Embedding dimensions do not necessarily have human-readable meanings.

LIMITATIONS
Traditional Word2Vec assigns one main vector to each vocabulary word.
One vector creates difficulty for words with multiple meanings.
The word 'bank' can have financial and geographical meanings.
Traditional Word2Vec does not automatically create separate contextual vectors for each sense.
Word2Vec has an out-of-vocabulary problem for unseen words.
Training data influences embedding quality.
Corpus bias can appear in learned vectors.
Word2Vec does not directly represent complete sentence meaning.
Word2Vec is not a question-answering model by itself.
Modern contextual transformer models can represent context more dynamically.

APPLICATIONS
Word2Vec can support document similarity.
Word2Vec can support text classification.
Word2Vec can support information retrieval.
Word2Vec can support recommendation systems.
Word2Vec can support clustering.
Word2Vec can support sentiment analysis.
Word2Vec can support named entity recognition features.
Word2Vec can support question retrieval.
Word2Vec can provide semantic features to machine-learning models.
Word2Vec can help match related terms in an NLP knowledge base.

QUESTION ANSWERING
A question-answering system can represent query words with embeddings.
Embedding similarity can help find related knowledge-base terms.
Word2Vec can identify contextual relationships between technical words.
A query containing 'automobile' may relate to text containing 'car' if the trained vectors place them near each other.
Word2Vec retrieval can complement lexical retrieval.
Embedding-based retrieval can reduce dependence on exact word matching.
Word2Vec does not determine whether a retrieved answer is factually correct.
Answer extraction requires additional processing.
Modern systems often use contextual embeddings for advanced question answering.
