GLOVE

DEFINITION
GloVe stands for Global Vectors for Word Representation.
GloVe is a word-embedding technique.
GloVe represents words as dense numerical vectors.
GloVe learns representations from word co-occurrence statistics.
Word co-occurrence measures how often words appear near one another.
GloVe uses global statistics from a corpus.
The method was designed to combine global statistics with vector representations.
GloVe embeddings can capture semantic relationships.
GloVe embeddings can also capture some syntactic relationships.
Cosine similarity can be used to compare GloVe vectors.

CO-OCCURRENCE MATRIX
A co-occurrence matrix records relationships between words.
Rows and columns of a co-occurrence matrix correspond to vocabulary terms.
A matrix cell can contain a co-occurrence count.
The definition of context window affects co-occurrence counts.
Words appearing near each other contribute to co-occurrence statistics.
Large corpora provide more statistical evidence.
Rare words may have sparse co-occurrence information.
Global statistics can capture broad corpus-level relationships.
GloVe uses co-occurrence information during training.
Co-occurrence statistics are not the same as sentence meaning.

TRAINING AND VECTORS
GloVe learns a vector representation for each vocabulary word.
Training aims to preserve useful information from co-occurrence patterns.
Vector dimensions are learned from the corpus.
Common pre-trained GloVe models have different embedding sizes.
Embedding size can be 50, 100, 200, or 300 dimensions in common releases.
Different corpora produce different GloVe embeddings.
Pre-trained embeddings can be reused in downstream NLP models.
Embeddings can be fine-tuned or kept fixed depending on the application.
Vector similarity can be measured mathematically.
Similar contextual usage can lead to nearby vectors.

ADVANTAGES
GloVe uses global corpus-level co-occurrence information.
GloVe can capture useful semantic associations.
GloVe is computationally practical compared with many larger neural models.
Pre-trained GloVe vectors can reduce training requirements.
GloVe can provide strong baseline features for NLP tasks.
GloVe vectors can be used with traditional machine-learning models.
GloVe can represent vocabulary items in compact dense vectors.
GloVe can support similarity search.
GloVe can support clustering of related words.
GloVe can support document-level NLP applications when combined with other representations.

LIMITATIONS
Traditional GloVe embeddings are static.
A static embedding normally gives one vector to a word across contexts.
Polysemous words can have multiple meanings but one traditional GloVe vector.
Context is not dynamically represented for each occurrence.
Unknown words can be a problem when they are absent from the vocabulary.
Embedding quality depends on the training corpus.
Corpus biases can be reflected in learned vectors.
GloVe does not directly encode complete sentence structure.
GloVe is not a complete language model.
GloVe is not a complete question-answering system.

APPLICATIONS
GloVe can be used in text classification.
GloVe can support sentiment analysis.
GloVe can support document similarity.
GloVe can support information retrieval.
GloVe can support clustering.
GloVe can support named entity recognition features.
GloVe can support semantic search.
GloVe can support question retrieval.
GloVe can be used to initialize neural NLP models.
GloVe can complement TF-IDF in hybrid retrieval systems.

QUESTION ANSWERING
A question-answering system can convert question terms into GloVe vectors.
Vector similarity can help retrieve semantically related documents.
GloVe can help when a question and document use related words.
Embedding similarity can complement exact keyword matching.
TF-IDF and GloVe can provide different retrieval signals.
GloVe can help represent technical NLP vocabulary.
GloVe does not itself extract the final answer from a document.
Answer extraction requires a separate model or rule-based step.
Contextual transformer embeddings can handle many ambiguities better than static GloVe vectors.
