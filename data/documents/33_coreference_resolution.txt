TITLE: Coreference Resolution
PURPOSE: Retrieval-friendly NLP knowledge for a generative question-answering system.
USAGE: Each statement is written as an atomic knowledge unit so semantic retrieval can return focused evidence.

SECTION: Core concepts
Coreference resolution identifies mentions in text that refer to the same underlying entity or discourse object.
A mention is a textual expression that refers to an entity or event.
A coreference chain groups mentions that refer to the same entity.
An antecedent is a prior expression that a later reference can point to.
Anaphora occurs when a reference depends on a preceding expression.
Cataphora occurs when a reference points to an expression introduced later.
Pronouns such as he, she, it, and they often require coreference resolution.
Nominal expressions can also participate in coreference chains.
Coreference resolution is a discourse-level NLP task.
Coreference information can support question answering, information extraction, summarization, and dialogue systems.

SECTION: Types of referring expressions
Pronouns are short referring expressions whose interpretation often depends on context.
Proper names can refer to entities introduced elsewhere in a document.
Definite noun phrases can refer to previously established entities.
Indefinite noun phrases can introduce new entities but may also refer to known entities in context.
Demonstratives such as this and that can refer to entities, events, or discourse segments.
Zero anaphora occurs when a reference is omitted but understood from context in some languages.
Event coreference determines whether two event mentions refer to the same event.
Entity coreference focuses on references to people, organizations, objects, and other entities.
Document-level coreference may require information from many sentences.
Conversational coreference can require dialogue history and speaker information.

SECTION: Mention detection
Mention detection identifies candidate spans that may refer to entities.
Rule-based mention detection can use noun-phrase and pronoun patterns.
Named entity recognition can provide useful candidate mentions.
Parsing can help identify noun phrases and grammatical structures.
Neural mention detectors can predict spans directly from contextual representations.
False positive mentions increase the search space for coreference resolution.
False negative mention detection can prevent correct coreference links from being created.
Mention boundaries can affect both coreference and downstream extraction.
Nested mentions may occur when one referring expression contains another.
Some systems perform mention detection jointly with coreference prediction.

SECTION: Coreference linking
Pairwise coreference models score whether two mentions refer to the same entity.
Antecedent ranking models score candidate antecedents for each mention.
Cluster-based methods construct groups of mutually coreferent mentions.
Recency can be a useful but imperfect heuristic for antecedent selection.
Grammatical agreement can provide evidence about candidate compatibility.
Number agreement can distinguish singular and plural candidates in many languages.
Gender agreement can provide evidence when grammatical or semantic gender is expressed.
Semantic compatibility can eliminate implausible antecedents.
Discourse salience can influence which entity a referring expression is likely to denote.
Global inference can improve consistency across a document.

SECTION: Algorithms and models
Traditional coreference systems often combine hand-written rules with statistical ranking.
Rule-based systems can encode constraints for pronouns, names, and noun phrases.
Feature-based machine learning models can rank candidate antecedents.
Neural coreference models use contextual embeddings to represent mentions.
Span-based models score candidate mention spans and possible antecedent links.
Transformer encoders can provide contextual representations for document-level coreference.
Clustering algorithms can group pairwise coreference predictions into chains.
End-to-end systems can jointly learn mention detection and coreference decisions.
Long-context models can help process documents with distant references.
Hybrid systems can combine neural predictions with deterministic linguistic constraints.

SECTION: Linguistic cues
Number agreement can indicate whether a pronoun refers to a singular or plural noun phrase.
Person agreement can help distinguish first-, second-, and third-person references.
Gender agreement can be useful where the language marks gender.
Subject prominence can influence antecedent preferences in some languages.
Parallel grammatical structures can provide clues for resolving references.
Semantic role information can help determine which entity is likely to be referenced.
Discourse topic can make one entity more salient than another.
World knowledge can be necessary to resolve references that syntax alone cannot determine.
Bridging references connect related but not necessarily identical entities.
Ambiguous pronouns may remain unresolved when multiple candidates satisfy the available constraints.

SECTION: Evaluation
Mention detection can be evaluated separately from coreference linking.
Coreference evaluation compares predicted clusters with annotated reference clusters.
MUC is an early metric based on links needed to connect mentions into clusters.
B-cubed evaluates mention-level precision and recall within clusters.
CEAF aligns predicted and reference clusters using a similarity function.
LEA evaluates coreference links while considering entity importance.
CoNLL-style coreference scores commonly aggregate several coreference metrics.
Exact cluster matching is stricter than link-based evaluation.
Evaluation can be sensitive to the mention annotation policy.
Human agreement provides a useful reference for the difficulty of the task.

SECTION: Applications and limitations
Question answering can use coreference to interpret pronouns in questions and documents.
Information extraction can merge facts expressed across multiple mentions of an entity.
Summarization can reduce repetition by recognizing repeated references.
Dialogue systems can use coreference to understand phrases such as that one or they.
Search systems can use entity chains to connect related passages.
Knowledge graph construction can benefit from resolving multiple mentions to one entity.
Long documents increase the number of possible antecedents and candidate links.
World knowledge requirements can make some references difficult to resolve automatically.
Errors in mention detection can propagate through the entire coreference pipeline.
Coreference systems should be evaluated on domains that resemble their deployment environment.
