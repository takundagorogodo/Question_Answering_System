N-GRAMS AND LANGUAGE MODELS

CORE CONCEPTS
An n-gram is a contiguous sequence of n tokens.
The value of n determines the length of the sequence.
A unigram contains one token.
A bigram contains two consecutive tokens.
A trigram contains three consecutive tokens.
A four-gram contains four consecutive tokens.
N-grams are usually generated after tokenization.
N-grams can be created from words or other token types.
Character n-grams use sequences of characters rather than words.
Word n-grams capture local word-order patterns.
N-grams are useful for representing local context.
An n-gram model estimates probabilities of token sequences.
Language models assign probabilities to possible sequences.
Traditional n-gram models commonly use counts from a corpus.

EXAMPLES
For 'I love NLP', the unigrams are I, love, and NLP.
For 'I love NLP', the bigrams include 'I love' and 'love NLP'.
For 'I love NLP', the trigram is 'I love NLP'.
For 'natural language processing', the bigrams are 'natural language' and 'language processing'.
For the same phrase, the trigram is 'natural language processing'.
N-gram extraction depends on tokenization rules.
Punctuation can be retained or removed depending on the application.
Start and end markers can be added to language-model training.
Special boundary tokens help model sentence beginnings and endings.
N-grams can be counted across a training corpus.
Repeated n-grams contribute repeated counts.
Frequency counts can be converted into probabilities.

LANGUAGE-MODEL PROBABILITY
A language model estimates how likely a sequence is.
A unigram model uses individual token probabilities.
A bigram model conditions a word on the previous word.
A trigram model conditions a word on the previous two words.
The chain rule can express a sentence probability as conditional probabilities.
N-gram models approximate the full chain-rule probability using limited context.
Bigram models assume the next word mainly depends on the previous word.
Trigram models use two previous words as context.
Larger n values can capture more local context.
Larger n values also require more training data.
Probability estimates are derived from corpus statistics.
Maximum-likelihood estimation uses observed counts.
Unseen n-grams can receive zero probability under an unsmoothed model.

SMOOTHING
Data sparsity is a major problem for n-gram language models.
Data sparsity means many possible n-grams are rare or unseen.
Zero probabilities can make sentence probabilities unusable.
Smoothing assigns probability mass to unseen or rare events.
Laplace smoothing adds a count to observed vocabulary events.
Lidstone smoothing generalizes add-one smoothing.
Good-Turing smoothing adjusts probabilities using frequency-of-frequency information.
Kneser-Ney smoothing is a strong smoothing method for n-gram language models.
Backoff models use shorter contexts when a longer context is unavailable.
Interpolation combines probabilities from different n-gram orders.
Smoothing changes probability estimates rather than language meaning.

USES
N-grams have been used in speech recognition.
N-grams have been used in spelling correction.
N-grams can support autocomplete.
N-grams can support text prediction.
N-grams can support machine translation systems.
N-grams can support information retrieval.
N-grams can detect common phrases.
N-grams can support phrase matching.
N-grams can be used as features in text classification.
N-grams can help compare a question with candidate documents.
N-grams can identify technical phrases in educational text.
N-grams can provide interpretable lexical features.

LIMITATIONS
Traditional n-gram models have a fixed context window.
Fixed context limits long-range dependency modeling.
Larger n values increase the number of possible combinations.
The number of possible n-grams grows rapidly with vocabulary size.
Large n-gram tables can consume substantial memory.
N-gram models do not directly represent deep semantic meaning.
Synonyms can appear as unrelated tokens in an n-gram model.
Word-order changes can strongly affect n-gram probabilities.
Rare phrases are difficult to estimate reliably.
Domain changes can make learned n-gram probabilities less useful.
Modern neural language models can represent broader contextual information.
Transformer models can use attention to model relationships over longer contexts.

QUESTION ANSWERING
N-grams can help identify phrases in an NLP question.
A question can be represented using unigrams, bigrams, and trigrams.
Important phrases can improve retrieval from a knowledge base.
The phrase 'named entity recognition' is a useful trigram.
The phrase 'bag of words' is a useful trigram.
N-gram overlap can provide a simple similarity signal.
N-gram features can be combined with TF-IDF.
N-gram features can be combined with embeddings.
N-grams can help detect repeated terminology in educational documents.
N-grams alone do not guarantee semantic understanding.
A question-answering system can use n-grams as one retrieval feature.
