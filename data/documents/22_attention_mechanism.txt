
Attention is a neural mechanism for weighting information.
Attention helps a model focus on relevant information.
Attention became central to modern NLP.
Self-attention relates tokens in the same sequence.
Cross-attention relates two different representations or sequences.
Attention can model long-range relationships.
Attention can be combined with RNNs.
Transformers use attention as a central operation.
Attention is commonly described using queries, keys, and values.
A query represents information seeking relevant context.
A key is used for matching with a query.
A value contains information that can be aggregated.
Attention compares queries with keys.
Similarity scores become attention weights.
Attention weights are applied to values.
The weighted values form the attention output.
Dot-product attention is commonly used.
Scaled dot-product attention scales attention scores.
Scaling helps control large dot products.
Self-attention lets a token interact with other tokens.
Bidirectional encoders can attend to both sides of a token.
Autoregressive decoders use causal masking.
Causal masking prevents access to future target tokens.
Multi-head attention uses multiple attention heads.
Each head can learn a different representation subspace.
Different heads can capture different relationships.
Head outputs are concatenated.
A projection combines multi-head outputs.
Transformer encoders use self-attention.
Transformer decoders use masked self-attention.
Encoder-decoder transformers also use cross-attention.
BERT uses transformer encoder attention.
GPT-style models use transformer decoder attention.
Attention supports parallel processing during training.
Full self-attention has quadratic token interaction cost.
Long sequences can require substantial attention memory.
Efficient attention methods target long contexts.
Attention weights are not complete explanations by themselves.
Attention does not guarantee factual correctness.
Attention can help question-answering systems focus on evidence.
Attention can connect question and passage representations.
Attention can help identify relevant passage tokens.
Attention is not itself a complete QA system.
Retrieval, reasoning, and generation can be separate components.
Contextual representations depend on surrounding tokens.
Attention can connect distant tokens directly.
