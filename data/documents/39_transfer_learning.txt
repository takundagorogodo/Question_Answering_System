TITLE: Transfer Learning
PURPOSE: Retrieval-friendly knowledge for a generative NLP question-answering system.
USAGE: Atomic statements support semantic retrieval, grounded answer generation, and focused knowledge lookup.

SECTION: Foundations
Transfer learning reuses knowledge from one task or dataset to improve another task.
The source task or domain provides parameters, representations, or examples that can be reused.
The target task is where transferred knowledge is applied.
Pretraining is a common form of transfer learning in NLP.
Fine-tuning is one way to adapt transferred parameters to a target task.
Feature-based transfer uses representations from a pretrained model.
Parameter transfer initializes a target model with parameters learned previously.
Transfer learning is useful when target-task labeled data is limited.
Negative transfer occurs when reused knowledge harms target-task performance.
Transfer effectiveness depends on source-target similarity and adaptation strategy.

SECTION: Transfer settings
Inductive transfer uses labeled target-task data and may involve a different task.
Domain adaptation addresses differences between source and target data distributions.
Cross-lingual transfer applies learned knowledge across languages.
Multitask learning trains on multiple tasks with shared model parameters.
Self-supervised pretraining learns from signals derived automatically from raw data.
Zero-shot transfer applies a model without task-specific training examples.
Few-shot transfer uses a small number of target-task examples.
Unsupervised transfer can use unlabeled target data.
Knowledge can transfer through model weights, representations, or synthetic examples.
Each transfer setting has different data and evaluation requirements.

SECTION: Pretrained models and adaptation
Pretrained language models learn linguistic patterns from large text collections.
Transformer encoders provide contextual representations useful for classification and extraction.
Encoder-decoder models support generation tasks such as translation and summarization.
Decoder-only models are often adapted for instruction following and generation.
Continued pretraining uses additional unlabeled text from the target domain.
Domain-specific fine-tuning uses labeled examples from the target domain.
Freezing layers reduces updates but may limit adaptation.
Gradual unfreezing updates selected pretrained layers over time.
Parameter-efficient tuning can reduce memory requirements.
Tokenizer coverage and pretraining data affect cross-domain and cross-language transfer.

SECTION: Domain and cross-lingual transfer
Domain shift occurs when deployment inputs differ from the training distribution.
Target examples should represent the intended deployment environment.
Pseudo-labeling uses model predictions as provisional labels for unlabeled examples.
Low-quality pseudo-labels can amplify existing errors.
Parallel corpora contain aligned examples in multiple languages.
Machine translation can create translated training examples for a target language.
Multilingual models share parameters across multiple languages.
Language-specific morphology and word order can affect transfer quality.
Pretraining coverage does not guarantee equal performance across languages.
Transfer should be evaluated separately for important domains and languages.

SECTION: Evaluation and applications
Transfer performance should be compared with a suitable target-task baseline.
Few-shot evaluation measures performance with limited labeled examples.
Zero-shot evaluation tests a task without task-specific labeled training data.
Cross-domain evaluation measures robustness to distribution changes.
Negative transfer is present when transfer performs worse than an appropriate baseline.
Data leakage can make transfer evaluations overly optimistic.
Sentiment analysis can benefit from pretrained representations when labels are scarce.
Named entity recognition can use contextual representations learned during pretraining.
Transfer learning supports translation, question answering, summarization, and classification.
Results should report data size, domain, language, adaptation method, and test conditions.
