
A sequence-to-sequence model is called a seq2seq model.
A seq2seq model maps one sequence to another sequence.
Input and output sequences can have different lengths.
Seq2seq models commonly use encoder-decoder architectures.
The encoder reads the input sequence.
The encoder produces internal representations.
The decoder generates the output sequence.
The decoder normally produces tokens sequentially.
A start token can mark the beginning of generation.
An end token can mark the end of generation.
Teacher forcing can be used during training.
Teacher forcing supplies the correct previous target token.
Greedy decoding selects the highest-probability next token.
Beam search keeps several candidate sequences.
Machine translation is a seq2seq application.
Text summarization is a seq2seq application.
Dialogue generation is a seq2seq application.
Generative question answering is a seq2seq application.
Grammar correction can use seq2seq models.
Paraphrase generation can use seq2seq models.
Text simplification can use seq2seq models.
Data-to-text generation can use seq2seq models.
Code generation can be treated as sequence generation.
RNNs can be used as seq2seq encoders.
LSTMs can be used as seq2seq encoders.
GRUs can be used as seq2seq encoders.
Transformers can be used in seq2seq systems.
Attention allows the decoder to focus on input positions.
Cross-attention connects decoder states with encoder representations.
Bahdanau attention is an early neural attention method.
Luong attention is another neural attention method.
Seq2seq models are trained on input-target pairs.
Cross-entropy is commonly used for token prediction.
Subword tokenization can reduce unknown-word problems.
Padding supports batching of variable-length sequences.
Masks prevent padding positions from affecting computation.
Long sequences can increase computation.
Autoregressive decoding can be slow for long outputs.
Seq2seq models can produce repetitive outputs.
Exposure bias can occur during sequence generation.

Generated answers can contain incorrect information.
