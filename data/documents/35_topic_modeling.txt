TITLE: Topic Modeling
PURPOSE: Retrieval-friendly NLP knowledge for a generative question-answering system.
USAGE: Each statement is written as an atomic knowledge unit so semantic retrieval can return focused evidence.

SECTION: Core concepts
Topic modeling identifies recurring latent themes or topics in a collection of documents.
A topic is represented as a pattern of words that tend to occur together.
Topic modeling is generally an unsupervised or weakly supervised text analysis technique.
Documents can be represented as mixtures of multiple topics.
Topic models are useful for discovering structure in large text collections.
Latent topics are inferred from observed word usage rather than always being manually labeled.
Topic modeling differs from document classification because topics are often learned without predefined classes.
A topic model can provide interpretable summaries of document collections.
Topic distributions can be used as features for downstream tasks.
Topic modeling is commonly applied to research papers, news, reviews, and archives.

SECTION: Latent Dirichlet allocation
Latent Dirichlet allocation, or LDA, is a probabilistic topic model.
LDA represents each document as a mixture of topics.
Each topic in LDA is represented as a probability distribution over words.
Each document has a topic proportion distribution.
The generative view of LDA assumes that documents are produced from latent topic mixtures.
Dirichlet distributions are used as priors over topic proportions and word distributions.
Topic-word probabilities indicate how strongly words are associated with a topic.
Document-topic probabilities indicate how strongly a document is associated with each topic.
LDA inference estimates hidden topic assignments from observed words.
The number of topics is commonly selected as a modeling hyperparameter.

SECTION: Other topic models
Non-negative matrix factorization can discover topic-like components from a document-term matrix.
Probabilistic latent semantic analysis models relationships between documents, words, and latent topics.
Hierarchical topic models organize topics into multiple levels.
Dynamic topic models track topic changes over time.
Neural topic models use neural representations to learn latent topic structures.
Embedding-based topic methods can cluster semantically similar documents or words.
BERTopic-style approaches combine document embeddings, clustering, and topic representation.
Correlated topic models allow topic proportions to exhibit correlations.
Author-topic models connect topics with document authors.
Model choice should depend on corpus size, interpretability requirements, and downstream goals.

SECTION: Preprocessing
Document preprocessing can strongly affect discovered topics.
Tokenization converts documents into processing units.
Stop-word removal can reduce common function words but should be used carefully.
Lemmatization can group related word forms under a common base form.
Stemming can reduce word variants using simpler morphological rules.
Very rare words may add noise to topic models.
Extremely common domain-specific words may dominate topics without adding useful distinction.
N-grams can capture meaningful multiword expressions.
Vocabulary filtering can reduce memory and computation.
Preprocessing should preserve terms that are important for the domain's topics.

SECTION: Topic interpretation
Topic-word rankings are commonly used to inspect the meaning of learned topics.
Top words alone may not always provide a complete interpretation of a topic.
Representative documents can help humans interpret topics.
Topic coherence measures attempt to estimate whether top topic words are semantically coherent.
Human labeling is often useful for assigning readable names to discovered topics.
Topic labels are interpretations rather than necessarily direct outputs of the model.
Two topics can be mathematically distinct but semantically similar.
Topic redundancy occurs when multiple topics represent nearly the same theme.
Topic drift can occur when the same vocabulary changes meaning across time or domains.
Interpretation should consider the corpus and the purpose of the analysis.

SECTION: Evaluation
Topic coherence measures are often used to assess the interpretability of topic-word sets.
Perplexity measures how well a probabilistic model predicts held-out word sequences under its assumptions.
Lower perplexity does not necessarily mean that human readers will find topics more coherent.
Topic diversity measures whether different topics contain distinct high-ranked words.
Human evaluation can ask annotators whether topics are interpretable and distinct.
Downstream evaluation can test whether topic representations improve another task.
Stability evaluation checks whether similar datasets or seeds produce similar topics.
Evaluation should consider both statistical fit and practical interpretability.
The selected number of topics can strongly affect model behavior.
Topic models should be evaluated using held-out data when predictive metrics are used.

SECTION: Applications
Topic modeling can organize large document collections by recurring themes.
Researchers can use topics to explore trends across scientific literature.
News analysis can identify recurring subjects and monitor changes over time.
Customer feedback can be grouped into themes such as delivery, quality, and service.
Search interfaces can use topic labels to help users browse document collections.
Topic distributions can support document recommendation.
Topic modeling can support exploratory analysis before building supervised classifiers.
Historical archives can be analyzed for changes in themes over time.
Topic models can help identify clusters of related documents.
Topic modeling is primarily exploratory and should not automatically be treated as definitive classification.

SECTION: Limitations
Topics are not guaranteed to correspond to human-defined concepts.
Bag-of-words models ignore much of word order and syntax.
Polysemous words can appear in multiple topics for different reasons.
Frequent generic terms can make topics difficult to interpret.
Very short documents may not contain enough information for stable topic inference.
Highly similar topics can be redundant.
Topic assignments can be sensitive to preprocessing and model hyperparameters.
Changing corpora can change the learned topic vocabulary.
Topic models may reflect biases and imbalances in the source collection.
Human interpretation remains important when topic labels are used for decisions.
